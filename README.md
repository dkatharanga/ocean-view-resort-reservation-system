# OceanView Resort Reservation Management System

![CI](https://github.com/dkatharanga/ocean-view-resort-reservation-system-ICBT/actions/workflows/backend-ci.yml/badge.svg)

## About
Hotel Reservation Management System built with:
- React 18 + Vite (Frontend)
- Spring Boot 3.2 + Java 17 (Backend)
- MongoDB Atlas (Database)

## How to Run

### Backend
```bash
cd oceanview/backend
./mvnw spring-boot:run
```

### Frontend
```bash
cd oceanview/frontend/oceanview-frontend
npm install
npm run dev
```
